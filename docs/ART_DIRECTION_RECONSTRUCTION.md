# Faridh / Sculptural Impasto V2 — Art Direction Reconstruction

## Decision / rejection

**REJECTED:** the former "serif headline + landscape image on the right + alternating beige sections" website. It technically passed browser checks, but did not produce the art direction planned by Lazarus.

**CURRENT FORM:** one complete, gallery-scale painting; typographic cover designed for the paintings' physical density; biography anchored by the real person; factual work and qualifications treated as an independent document atlas, not illustrated fiction.

This is a **different page grammar**, not a palette change to the previous component template. The identity of the visitor is a legal/HRGA professional, *not* a fictional web developer.

## Full-page composition / editorial rhythm

1. **The Cover** — typographic exhibition masthead on restrained canvas. Independent full-width art follows it. Clear, live CTA.
2. **The Dossier** — portrait first-party evidence and actual biography, separate from the fictional metaphor.
3. **The Work Ledger** — four native details disclosures, with company/dates/tangible responsibilities untouched; this section deliberately has no painting.
4. **The Material Intermission** — a second uninterrupted original oil painting in a distinct rust-toned publication chapter. No false professional attribution.
5. **The Tool Index** — four professional skill families as a usable typographic classification.
6. **The Academic Record** — 3,76/4,00 and four training records in a composed index.
7. **The Contact** — plain live email and WhatsApp; human action is the true endpoint.

## Design constraints from the user's selected art direction

- Exactly one painting image for each depicted scene. Two complete 1536×1024 artworks used; the third research painting stays in assets/ but not inserted merely to decorate a section.
- No SVG art, CSS composites, image stacks, 3D DOM transformations, procedural fog, moving statues or cut-out parallax.
- Text/control UI is completely independent of painted image pixels.
- Real portrait preserved from existing primary repo without generative alteration.
- Fraunces used as a considered distinctive masthead/archival display face; IBM Plex Sans for readable work details and IBM Plex Mono for documentary marginalia. The typography can be rejected if an independent reviewer finds it unsuitable, but is not derived from a default headline+image recipe.
- Mobile recomposes through actual media queries; image remains complete and intrinsic at 320 and 390. Accessibility includes a skip link, native disclosures, labels, semantic roles and reduced-motion fallback.

## Known limits and truthfulness

This work preserves facts from the pre-existing CV-grounded website. The original CV PDF was not provided anew in this specific reconstruction turn; source verification is against the previous site, not a new reading of the PDF. The oil artworks were generated by Lazarus as conceptual images, not Faridh's professional design projects. The site must not invent projects, professional experience or first-person quotes.

Browser CI proves functional rendering and layout measurements. Originality, the desirability of this palette for a legal professional, optical type nuances and actual paint material quality require a human art-director judgement using real screenshots.
